# ElementalPassives - Minecraft Plugin Project

Target Version: Paper/Spigot 1.20 - 1.21+ (Java 17 or 21)

## Zero-IDE 1-Click Build:

### On Linux / macOS / Git Bash:
chmod +x build.sh
./build.sh

### On Windows PowerShell:
.\build.ps1

### On GitHub:
Push this folder to any GitHub repo, and the included .github/workflows/build.yml will automatically build and publish the ElementalPassives.jar in GitHub Actions Artifacts!
